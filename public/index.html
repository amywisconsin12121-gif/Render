Connect this server to regular ChatGPT Chat to search for existing images and inspect their actual pixels.

Your private connection

Paste MCP_SECRET from your hosting settings. It stays in this browser; this page uses it to calculate your connection URL.

  1. Open ChatGPT → Plugins → + → Add custom MCP server.
  2. Name it Image Scout. Paste this URL and choose No authentication. The secret in the URL controls access.
  3. Create and enable it. Start a new Chat, then select @Image Scout.
  4. Ask: Run the vision self-test and check the code you see.

The self-test checks whether this ChatGPT client receives tool images. If it fails, do not rely on claims of visual inspection. Custom tools depend on your account and workspace settings.
